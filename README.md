# Homework & Coding Practice Repo

A personal archive of homework assignments and coding exercises — saved here so I can look back at techniques, patterns, and solutions when I need a reference.

---

## What's in Here

This repo is a running collection of practice code across different topics. It's not perfectly organized, but each folder/file is labeled by topic or assignment so it's easy to search through.

---

## Why This Exists

- To have a quick reference when I forget how something works
- To track progress over time
- To avoid re-solving the same problem from scratch
- To keep homework/practice code in one place instead of scattered folders

---

## Work in Progress

This repo grows as I study, not just coding but also github itself. Not everything is clean or complete — some files are rough drafts or partial solutions. The goal is to learn and refer, not perfection.
